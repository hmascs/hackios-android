# HackiOS 0.3.5

Android 13+；iOS 虚拟机要求 ARM64 宿主。保留 2 vCPU 默认与 OSMesa 系统渲染。沿用现有 iOS 镜像版本，不强制重新编译系统镜像。

- **驱动**（0.31.0 已移除）：设置 → 驱动 → 导入驱动配置或 ZIP 包。导入后在对应槽位手动选用；“内置驱动”可恢复默认。v1 是声明式配置，运行参数由内置驱动生成，不接收 `.so`、脚本、内核模块或自定义 QEMU 参数。见 [驱动接口 v1](driver-packages.md)。
- **存储**：设置 → 存储 → 实验数据盘容量，选择 1–128 GiB 时，下次启动挂载该容量的私有稀疏只读盘。不同容量使用不同文件，不修改已有镜像。旧公共盘只能单独选择只读挂载，不是 iOS 的可写 `/private/var`。见 [可配置存储](android-configurable-storage.md)。
- **取帧**：解析 QEMU 对齐的 PPM 行以避免图像错位；控制连接复用，并调整截图调度，减少启动和无画面交互时的采样负担。没有承诺更短的真机启动时间。
- **Adreno**：同一次独立启动已经验证 `backboardd` → Adreno 830 → IOSurface → SpringBoard 主屏与点击后可辨认的设置页面；尚未证明普通 APK 进程的硬件部署，也没有证明性能优于 OSMesa。0.3.5 不启用实验后端；维持 OSMesa。异构 GPU、Metal、外部二进制驱动与可写 iOS 数据迁移不在本版可用范围。

APK 可使用与既有本地 0.30 调试包匹配的证书签名以支持在该签名链上的覆盖安装；其他证书的版本不应卸载后强装，先备份数据。
